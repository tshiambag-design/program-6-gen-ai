 Part 1: Determine the Problem

 Problem

The problem I want Gen‑AI to solve is to create a simple Java program that use Object‑Oriented Programming (OOP) and one of the data structures we learned this quarter. I chose to build a small Task Manager program.

The program should:

- Create a Task class with field like name, priority, and whether the task is completed.
- Use an ArrayList to store multiple Task objects.
- Allow the user to add task, list all tasks, and mark tasks as completed.

 Initial Prompt for AI

Write a Java program using OOP that manage a list of tasks.
Create a Task class with fields for name, priority, and completed status.
Use an ArrayList to store Task objects.
Include methods to add tasks, list tasks, and mark tasks as done.
